# MASTER_PROMPT

Kopiere den Block unten in ChatGPT (Chat, Work) oder Codex. Er startet die Arbeit mit diesem Repo.

---

```
Du arbeitest mit meinem GitHub-Repo Nico5680/chatgpt-skills (Branch main).

SCHRITT 1 - LESEN
Lies in dieser Reihenfolge: README.md, AGENTS.md, COMPATIBILITY.md, SOURCES.md.
Lies danach die SKILL.md der Ordner preflight-routing, deep-research-log, weekly-dump-publisher und skill-creator.

SCHRITT 2 - PRUEFEN
Pruefe, was in deiner aktuellen Umgebung (Chat/Work oder Codex) tatsaechlich funktioniert:
Kannst du Dateien im Repo lesen? Schreiben? Skripte ausfuehren? Drive/Google Site erreichen?
Sage mir das in einer kurzen Tabelle.

SCHRITT 3 - AUSWAHL
Gehe SOURCES.md durch. Waehle aus den dortigen Repos die Skills, die
(a) in deiner Umgebung ohne Skripte laufen und
(b) nichts Gleichwertiges in diesem Repo haben.
Begruende jede Auswahl in einem Satz. Uebernimm nichts unbesehen: Lizenz pruefen, Skripte und Netzwerkzugriffe lesen, Inhalte auf Deutsch anpassen, wenn sinnvoll. Alles Risikoreiche (Skripte mit Netzwerk, Loeschen, Zugangsdaten, fremder Code mit unklarer Lizenz) komplett weglassen.
Skills, die nur mit Codex/CLI laufen, nicht verwerfen, sondern in COMPATIBILITY.md unter "Nur Codex - spaeter" vormerken.

SCHRITT 4 - UMSETZEN
Lege jeden uebernommenen Skill als Ordner <name>/SKILL.md (+ agents/openai.yaml) an. Ueberschreibe keine bestehenden Dateien. Passe AGENTS.md nur minimal an (Routing-Zeile hinzufuegen), wenn das einen echten Nutzen hat.

SCHRITT 5 - BERICHT
Gib mir eine kurze Liste: uebernommen, vorgemerkt, abgelehnt (mit Grund), und was ich als Naechstes tun soll.

Arbeite ohne Rueckfragen weiter, ausser etwas ist wirklich unklar.
```
